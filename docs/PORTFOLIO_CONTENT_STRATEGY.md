# Content strategy

The portfolio addresses recruiters, engineering collaborators and potential clients. The primary action is to inspect evidence of work; secondary actions are downloading the CV and contacting Paul. The professional identity is **Paul Napoleon Phiri, Full-Stack Software Developer**, based in Blantyre, Malawi. Programming began in 2023; formal software employment began in 2026.

The homepage introduces the person, development journey, capabilities, employment, selected systems and contact path. `/projects` supports discovery by application type and relationship. Each `/projects/[slug]` page states the problem, Paul's role, implemented workflows, engineering approach, quality evidence, deployment state and learning. `/resume` presents the verified public PDF as the only résumé source served to users.

Status terms describe evidence, not marketing aspirations. “Prototype” is used for the banking and academic prototypes. “Under review” is used for the Terex redesign. “In development” is used where release is unverified. No case study claims production deployment, user counts, financial impact or sole authorship of shared products.

Services remain enquiry based. The current portfolio does not expose pricing, private repositories, internal evidence files or customer records.
