## Publication checks

Before adding a capture, verify its source commit or local version, the contributor's role, demo data, publication permission, visible text, loaded state and file size. Record the exact source directory and any permission evidence privately. When a safe, authentic capture is unavailable, keep the text based case study.

ZikoSpace's seeded sample property photos load from `images.unsplash.com`; the [Unsplash License](https://unsplash.com/license) permits use of Unsplash images in this context. The listings and accommodation names are local demonstration records, not claims about real available properties.
